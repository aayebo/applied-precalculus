Computational Resource Guide

Each chapter has a numbered folder of R and Python scripts in the companion source package. Run the scripts from their own folders or set the working directory appropriately. The code is intended to support numerical experimentation, graphical verification, and interpretation, not to replace algebraic derivation or mathematical proof. Figures reproduced by scripts should be checked for labeling, units, domains, and computational assumptions.

Editorial and Verification Notes

This expanded edition preserves the original sixteen chapters and adds a model-based application, paired computational scripts, and a report project to each chapter. New examples use illustrative rather than empirical data. Mathematical peer review, comprehensive R execution testing, independent exercise-solution verification, and permission checks should be completed before publication. Page counts depend on final print trim, typography, and placement of figures and code.
