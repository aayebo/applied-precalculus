Preface

This volume prepares students for calculus by developing algebraic fluency, function sense, trigonometric reasoning, geometric representation, and mathematical modeling. Each chapter combines mathematical explanations with worked examples, visual investigations, guided practice, and computational laboratories. The R and Python examples appear sequentially, not side by side. Students should first reason about the mathematics, then use code to explore, check, and interpret results. The scientific and health-related settings are instructional examples, not clinical recommendations.

How to Use This Book

Begin each chapter with its learning outcomes. Work examples by hand and attempt guided practice before reviewing solutions. For computational activities, execute the complete R listing and then the Python listing. Separate, runnable scripts are provided in the companion project under code/chXX/. Figures are collected under figures/chXX/. The selected-answer files are retained separately for instructor preparation.
